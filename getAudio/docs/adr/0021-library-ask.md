# 0021 资料库的「问」：本机 Claude 跑只读的 look.py 找转写；没有 Claude 退回只看目录

日期：2026-10-19

## 背景

用户 10-19：「借鉴 Ephemeris 的问，但是用来找转写」，接着「Moye 也做了个，互相参考」。资料库的搜索只认字面：
要记得原话里的某个词才搜得到，「上周宿舍里那段俄语讲模型的录音」这种描述搜不出来。

两个现成的做法：
- 墨页的「问」（pdf2md-web `server/find.mjs`，10-18）：整库目录（AI 标题、一句话、标签）一次交给模型，返回最多 8 份 + 一句理由；
  模型编出来的编号丢掉。墨页 319 份，Haiku 约 10 秒。
- Ephemeris 的「问 Claude」（`qa.py` + `look.py`）：本机 Claude Code 只被允许跑一条只读命令，自己搜原文、读前后文再答。

Verbatim 有 3574 份转写、正文几千万字，目录一次塞进去约 29 万字；而且人记得的常常是录音里说过的话，标题里没有。

## 决定

1. **界面和返回的样子照墨页**：搜索框里一个「问」，回车或点它；不聊天、不写长回答；最多 8 份，每份一句理由，
   多一个「跳到 07:41」和那句原话；短号对不上的、重复的丢掉，时间对到那份里真有的一句。
2. **查法照 Ephemeris**：本机 Claude Code（Sonnet 5.5，medium）只放行 `python look.py`，命令有 search / hits / read / info /
   list / stats / schema / sql，全部只读（sql 用 `mode=ro` 打开 library.db）。查的过程（搜了什么、读了哪份）实时显示。
3. **没有 Claude Code 时退回墨页的做法**：最新的转写目录（最多 6 万字）一次交给便宜模型（llmroute → Gemini flash-lite），
   界面说清楚只看了标题和简介、没看正文。
4. 同一时间只问一个，状态在内存里（重启就没了）；不存历史：这是找东西，不是对话。

## 后果

- 走订阅额度，记 $0；10-19 真库实测 12–17 秒、4–8 步。退回只看目录时一次约 3 万 token，flash-lite 不到 $0.01。
- 用的是 library.db 的索引，跟搜索同一份；转写刚写完没调 `library.changed` 的最多晚 60 秒才搜得到。
- 墨页可以反过来借这边的「查正文」：它现在只看目录，文档多了或要按内容找时会不够。
