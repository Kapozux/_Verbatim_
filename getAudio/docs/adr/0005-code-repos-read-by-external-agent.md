# 0005 代码库当来源：外部读码 agent 出卡，Verbatim 只核对

日期：2026-10-02

## 背景

用户想把自己的代码库放进项目，跟录音、文档一起提问（「这个项目的转写流程怎么走」「README 说的和代码对得上吗」）。
现有抽卡是把一期内容一次喂给便宜模型；读代码要 grep、顺着调用跳、看测试，一次性提示做不好。用户有自己写的
SWE agent Daemon（`~/Documents/Code_no_big_AI`，无头模式 `My_agent.py task.txt`，走 DeepSeek / Kimi）。

考虑过的做法：
- **代码按文件切成原文段落直接进语料**：不花钱，但整个仓库会把语料撑爆，自然语言问题按关键词也检索不到代码。
- **Verbatim 内置一个读码 agent**：重复造 Daemon，还要在 Flask 里维护工具调用循环。
- **Daemon 直接回答问题**：一问几分钟，答案带不了能点开核对的出处。

## 决定

1. **Daemon 读、Verbatim 核对。** Daemon 按 `repos.DAEMON_MD` 的格式写 `verbatim_cards.jsonl`：路径、行号、
   原样代码（quote）、观察（obs）、层级（主张 = 文档 / 注释怎么说，自证 = 代码怎么做，核实 = 测试证明）。
   Verbatim 逐字对快照：行号对就收；原文在别处且只有一处就改行号；只差首尾空白就按原文定位、存文件里的原文；
   对不上就丢；跟已有的卡同一段或被它整段包住算重复。不调模型。
2. **只在快照里跑。** `git archive <commit>` 解到 `results/_repos/<id>/snapshot/`：只有提交过的文件，
   按文件名和内容挑掉像密钥的；commit 钉住，出处写成「文件:行 @commit」。快照自己 `git init`，
   跑完看 Daemon 动没动别的文件，下一次跑前还原。Daemon 会执行 shell，快照之外的东西它碰不到是靠
   cwd 和它自己的危险命令拦截，不是沙箱——所以只由用户手动点「读」触发，演示模式不开。
3. **不改 Daemon 的接口。** 规矩和格式通过它本来就会读的 `DAEMON.md` 放进快照；task.txt 是这次的问题。
   Verbatim 自带一份副本 `daemon/`（见 daemon/README.md）：其余文件照抄（危险命令拦截按用户同意放宽了误拦：
   只读命令放行、同名文件只在 Daemon 自己目录里算它的），只换 `llm.py`——
   用 Settings 里的 DashScope key 走阿里云、记进 usage.db、内容审查拒收时跳过那段输出。
   `VERBATIM_DAEMON_DIR` 可改用外面那份。
4. **卡片只追加。** 每次读（导览或带着问题）新卡接在后面，下标 i 不变；出处 id `r<固定编号>-<i>`，
   提示词里用短别名 `r1-3`（跟文档段落的 `d2-3` 一样，见 citations.prompt_id）。
5. **界面**：代码库是来源（左栏 + 来源栏阅读器），见 UI_DESIGN 位置表；加完不自动读，先弹框看估价
   （按行数估 token、按价格表算钱，2026-10-02 拟合「15 万 + 每行 16 个」输入 token）。
6. **不跟着代码改动自动重读**（见「AI 文本定期写」那条约定）：commit 变了要重新加，或手动再读。

## 后果

- 自带副本的费用进 `usage.db`（purpose = repo_read）；外面那份不进。阿里云的 deepseek-v4-pro 价格表里没有，只记 token。
- 2026-10-02 试跑：5 个文件的仓库 12/12 张卡逐字对上；1.8 万行的 getAudio 前两次 0 张——DeepSeek 跑到十几轮后
  改用自带的 `<invoke>` 工具调用写法，Daemon 解析不了就退出了（退出码 0）。Daemon 那边加了兜底解析和带格式的提醒。
  副本走阿里云真跑一次 getAudio：5 分钟、47 次调用、输入约 91 万 token / 输出 1.4 万；13 张卡里 5 张跟上次同一段（去重），
  7 张新收，1 张只是第一行丢了缩进——核对改成「只差首尾空白时按原文定位、收文件里的原文」后也收下。
- 卡片的位置字段（时间 / 页 / 文件:行 / 画面帧）现在各走各的：代码库卡把「文件:起-止」放在 heading，
  另加 path / line / repo_id。2026-10-02 跟画面证据卡那边说定：画面卡还不一定进提问语料（先做评测），
  现在不为它改 card_view；真要进的时候一起迁成一个 `loc` 对象（{kind: time | page | lines | frame, …}，
  画面帧是 {kind: 'frame', task_id, sec, until, img}，点开退回到转写那一秒），代码库卡的 path / line 也挪进去。
