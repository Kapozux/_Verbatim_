# 博主按引用进项目，用固定字母，字母永不复用

一个博主可以放进几个项目，他的转写、证据卡、画像只在他自己的链条里存一份、算一次；项目只在 `sources.json`
里记 `{chain_id, tag}`。项目里提问时他的卡片 id 写成 `B:3-12`，这个 id 会存进聊天记录和工作台产出，所以字母
一旦发出去就跟这个人绑定：从项目里拿掉的字母记进 `retired_tags`，再也不发给别人——否则旧回答的出处会指到另一个人身上。

## Considered Options

- 把博主的卡片拷进项目：简单，但每个项目各算一遍、各花一份钱，博主同步更新后项目里的是旧的。
- 用博主的链条 id 当前缀：不会撞，但 32 位 id 太长，模型会把它缩写坏（同样的问题让原文段落改用了短别名）。
