# 0015 问证据卡可以交给本机 Claude Code 写（只在自己电脑上开）

日期：2026-10-13

## 背景

用户有 Claude 订阅，按 API 价折算一周能用上千美元的量，平时远用不完；问答是最在意质量的地方（要引对卡、讲清前后变化），
原来是 gemini-3.5-flash-lite / DeepSeek V4 Flash。但 Verbatim 会发给别人用（DMG / 演示），别人的电脑上没有 Claude Code。

## 决定

1. 加一个开关 `ASK_ENGINE=claude`（默认空 = 跟以前一样）。开了、且有 `claude` 命令时，问证据卡由本机 `claude -p`（Opus 5.5）写，
   只换「写」那一步：挑卡、出处校验、改写语言、聊天记录都不变。
2. Claude 用不了（没装、没登录、撞上限）就照旧用原来的模型——这是日常文字，跟 0013 里「日常文字也先用它」那个开关一样可以回退。
3. 记账记 `claude-code`、$0、token 照记：订阅额度不是这次调用的实际花费，记成钱会让费用页失真。
4. 一次性调用关掉缓存写入；同时最多 3 个进程，免得几百次调用挤进一个 5 小时窗口（Ephemeris 10-13 全量做卡撞过）。

## 后果

- 打包版、演示实例、没装 Claude Code 的人完全不受影响。
- 抽证据卡、画像、镜头不归这个开关管，仍按项目的分析模型（DeepSeek / Gemini）走（用户 10-13：Verbatim 抽卡不用 Claude）。
- 测试：`tests/test_claude_ask.py`。
