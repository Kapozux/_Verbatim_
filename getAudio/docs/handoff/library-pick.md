# 资料库勾选合并（照墨页的选择 + 下载合并 .md）

## 速览

- **现状**：分支 `feature/lib-pick` 已本地提交。64 个测试文件全过（`tests/test_merge_md.py` 8 项）。
- **怎么跑**：资料库 → 转写记录，把鼠标放到卡片上，左边出现勾选框；勾了以后底部出现浮动条，点「下载合并 .md」直接存文件，「合并」先预览。
- **已知问题**：勾选只存在内存里（跟博主分集页的购物车一样），刷新就清空；没有「全选」。
- **下一步**：用一阵后看要不要「全选当前筛选结果」、合并时要不要带时间戳。

## 做了什么

- `buildHistoryCard(entry, { pick: true })`：资料库列表和「问」的结果卡片带勾选框；跟博主分集页共用 `mergeCart`，`syncPicks()` 让同一份在几处一起变。
- 浮动条多了「下载合并 .md」（`downloadMergedMd`）：照墨页，不打开预览直接下载。
- `/api/transcripts/merge`：每份标题下面加一行出处（转写日期 · 时长 · 博主 · 原链接或文件名，`_transcript_source_line`），照墨页合并时每份标来源。
- 样式：`.hist-pick`（平时 opacity 0，悬停 / `body.picking` / 触屏显示），`.history-item.picked` 珊瑚浅底；窄屏勾选框挂右上角、浮动条铺满宽度换行。
