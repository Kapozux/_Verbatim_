## 经验：做对了什么

### 1. 音乐是最大的瓶颈，先查音乐再改画面
- 前面十几版一直改画面、改节奏，用户都说不得劲。把配乐换成 Canvas 原曲做内部测试，用户马上说「牛逼爆了」，这才确认问题在音乐。
- 用 AI 生成配乐（Lyria 3.5，三首）被用户评价为「都是垃圾」。
- 「不得劲」的根本原因是**情绪和音乐反着走**：
  - 基础音量 0.5，人声一出来再压到 0.2，相当于把音乐抽掉四次。
  - 两个爆点正好被人声压掉。
  - 曲子的结尾没用上，最后还淡出。
- 改成下面这样就好了：
  - 基础音量 0.95，有人声时只压到 0.42。
  - **最重要的一句原声放进曲子自己安静的地方**，话一说完，爆点正好砸下来。
  - 最满的画面放在音乐最满的地方。
  - 曲子整首用完，不淡出。

### 2. 结构学 Canvas，学骨架，不学像素
- 首尾呼应要完整：图标 → **产品窗口** → 例子 → **回到同一个窗口** → 图标和行动号召。少了中间那个窗口，结尾就没有回家的感觉。
- 一个窗口贯穿到底，窗口里只换内容。不要用黑底字卡串场：每张黑卡都会把情绪清零，节奏像翻 PPT。
- 段和段之间靠形变衔接：播放头变成图标、① 推成全屏、视频缩回缩略图、一句原话缩成字幕墙上的一行、来源画面飞回左栏。
- 规模一级级放大：一期视频 → 一门课 → 一整个频道 → 生成各种成品。每个人只出现一段。
- 手机上要看清：要读的字不小于 44px；被点的那个控件，镜头推近 1.8–2.5 倍，其他内容压暗。
- 口号只说一次，留到最后当总结。不要在中段先用掉。

### 3. 用户的硬性要求（逐条都踩过）
- 用真实人脸和原声；**原声必须说完**，不能切在半句上。
- 节奏不能赶，也不能拖。每个功能只做一个连续动作，学 Canvas，大约 1.7 秒一项。
- 不要以小Lin说开头。用户妈妈说那样「像在讲小Lin说」。
- 保留现在的双引号图标，新画的图标都被否了。
- 场景不能重复：不要每段都是提问、卡片都在同一个位置、说法都一样。每个例子的问题不同、答案形式不同（一个数字 / 一个统计 / 讲解加翻译）、画面位置也不同。

### 4. 做法和工具
- **逐帧拆参考片**：用 `~/verbatim_outreach/promo/ref/analyze_motion.py`、`frames_compare.py` 算光流、找切点、量每段时长，再跑 `.venv/bin/python`。用户要的是「有多少帧算多少帧」，不要抽样。
- **出图检查**：渲染关键帧后拼成一张接触表看，比整片渲染快得多。
  - 抽帧：`npx remotion still src/index.ts <合成> out/x.png --frame=N`
  - 拼表：`ffmpeg -pattern_type glob -i 's*.png' -vf "scale=384:-1,tile=6x7" sheet.png`
- **找节拍**：先用梳状滤波在大范围里搜 BPM。只用自相关会把 120 测成 117.5，Incredible 一开始就是这么测错的。爆点用静音段的结束位置来找。
- **配乐对点**：参考曲和片子的爆点间隔对不上时，把曲子剪成几段拼起来：
  - 每个接口都放在拍点上；
  - 尽量藏在画面切换或者曲子安静的地方；
  - 跳过的拍数最好是偶数，否则底鼓和军鼓会错位。
- **响度**：
  - 人声素材统一 `loudnorm=I=-14`。
  - Artlist 下载的文件本身峰值到了 1.78，要先 `volume=-6dB,alimiter=limit=0.85` 再用，否则成片会破音。
  - 每次导出都检查峰值和每 0.5 秒的响度。
- **大改之前先开 workflow 诊断**：三个角度看片（对照 Canvas / 普通观众 / 音画冲击力）→ 三个方向出分镜 → 评审合成。约 70 万 token，16 分钟，定位得比自己猜准得多。方案全文在 `~/verbatim_outreach/promo/v14_方案_终审.md`。
- **转码**：`ffmpeg -i out/x.mp4 -r 30 -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart 成片.mp4`

### 5. 版权
- Google Canvas 的原曲、JAY-Z 的歌：只能内部测试，文件名里写明「仅内部测试_勿发」。
- Canvas 那首查不到出处：视频说明里没写，Shazam 也认不出来，应该是 Google 定制的配乐。最后用 Artlist 的 Song Match，贴入 Canvas 视频链接，找到相似曲，用户订阅后下载。
- 片尾要写素材出处和配乐署名。

## 没解决的问题：需求 / 定位

朋友杨子云看了 Canvas 配乐版，说看不懂，提到「那个什么妈妈……」。两种可能：
1. **只是梗没看懂**：步步高那句广告词要大约 85–00 年出生的人才熟，而且它在第 4 秒出现，那时观众还没感受到痛点。改法：开头用大白话，梗挪到片尾。
2. **需求本身打不动人**：「在长视频里找某人说过的某句话」，对学生、做研究的、做自媒体的人是真痛点，对只是刷视频消遣的人可能根本不存在。这样的话要先重新想定位，再谈宣传片。用户 10-04 在想这件事，见 `docs/positioning.md`（用户还没提交的文件）。
