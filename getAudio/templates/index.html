Tips: links, time ranges, playlists, local paths

Links download & transcribe (YouTube, Bilibili & other yt-dlp sites; for a whole channel, use Creators). Local paths are read in place, nothing uploaded. Note: macOS blocks reading from Downloads/Desktop, keep files in Documents or another folder.
Only want part of a video? Add a time range after the link: …/watch?v=xxx @10:00-25:00 (or @5:30- to the end): only that clip is downloaded & transcribed, cheaper, and timestamps stay at the real video position.
A collection / playlist link (e.g. a Bilibili 合集, a YouTube playlist) is expanded into its videos and each one is transcribed. Transcripts only, no analysis.

Gemini

Powers cloud transcription, summaries, and the pipeline analysis. Everything stays on this machine except the calls to Google.

DashScope

Alibaba Cloud key. Powers the Qwen-ASR engine, the speaker diarization half of Precise, and the Alibaba analysis models. ⚠ It moderates content, so don't use it for politically sensitive audio; prefer local Whisper or Gemini for that.

OpenRouter

One key for Claude and other frontier models. Powers the Claude Opus analysis options in Creators (with thinking enabled). No content moderation. Note: Opus is premium-priced and the pipeline analyzes every episode, so cost scales with episode count.

Models

Saved instantly. The next task picks them up, no restart. Leave a field blank to use the default.

DeepSeek / Kimi / GLM / Qwen model names are per-analysis presets (pick the model in the Creators form).

About

Verbatim is a local, self-hosted tool that turns audio and video into transcripts, then into cross-episode research.

Keys you enter here are stored only in settings.local.json on this machine and are never sent anywhere except to the provider they belong to. Leave a key field blank to keep the current one.
