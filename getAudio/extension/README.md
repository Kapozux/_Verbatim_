# Verbatim 浏览器插件

在 YouTube、B 站等视频页点一下，本机的 Verbatim 就会在后台下载并转写这个视频，转好后弹系统通知。

## 安装（Chrome / Edge / Arc）

1. 先把 Verbatim 开起来（默认 `http://localhost:5001`）。
2. 浏览器打开 `chrome://extensions`，右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选这个 `extension` 文件夹。
4. 把工具栏上的 Verbatim 图标固定出来。

## 用法

- **工具栏图标**：「转写整个视频」；正在看的视频还会多出一个「从 12:34 开始转」；可以选转完放进哪个笔记本。
  下面列着最近提交的任务和进度，转好的点一下就打开稿子。
- **右键**：在页面上右键 →「用 Verbatim 转写这个视频」；在视频链接上右键 →「用 Verbatim 转写这个链接」。
- **快捷键**：`Alt+Shift+V`（在 `chrome://extensions/shortcuts` 里可以改）。
- **设置**（弹窗右上角齿轮）：Verbatim 地址、密码 / 令牌（Verbatim 设了才填）、转写引擎、要不要用视频自带字幕。

视频自带字幕的话几秒就转好、不花钱；没有字幕就用设置里的引擎转，跟在 Verbatim 里贴链接一样计费。
